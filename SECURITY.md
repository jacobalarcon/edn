# Security policy

Please do not report security vulnerabilities in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/jacobalarcon/edn/security/advisories/new) with a concise description, reproduction steps, affected EDN and macOS versions, and the practical impact. You will receive an acknowledgement as soon as possible.

Security fixes target the latest published EDN release. Older technical-preview builds may be asked to update before a report is investigated.
